# ScreenCue website

This repository publishes the website for **ScreenCue**, a private teleprompter for PowerPoint speaker notes on Windows.

- Website: https://preethamshenoy-ai.github.io/screencue-site/
- Get ScreenCue from the Microsoft Store: https://apps.microsoft.com/detail/9N0VF85M0GS3
- Fact sheet: https://preethamshenoy-ai.github.io/screencue-site/facts.html

Guides:

- How to see your speaker notes while sharing your screen: https://preethamshenoy-ai.github.io/screencue-site/speaker-notes-while-screen-sharing.html
- How to use your PowerPoint speaker notes as a teleprompter: https://preethamshenoy-ai.github.io/screencue-site/powerpoint-teleprompter.html
- How to read a script while recording your screen on Windows: https://preethamshenoy-ai.github.io/screencue-site/teleprompter-for-screen-recording.html

ScreenCue shows your speaker notes in an always-on-top window over your slides. On Windows 10 version 2004 or later and Windows 11, Windows leaves that window out when you share or record your screen, so your audience sees only your slides. It can follow and control a running PowerPoint slideshow, opens Word, text and Markdown notes too, and works locally with no account, cloud sync or telemetry.
