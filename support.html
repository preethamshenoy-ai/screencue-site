ScreenCue support

ScreenCue is a local Windows teleprompter for PowerPoint speaker notes, made by PeteStudioz.ai.

System requirements

  • Windows 10 version 1809 or later, or Windows 11
  • PowerPoint desktop for slideshow sync, PowerPoint-controlled navigation, legacy .ppt files, and protected/repaired presentations
  • No PowerPoint installation is needed to read standard .pptx, Word .docx, text, or Markdown notes locally

Getting started

  1. Open a presentation or notes document.
  2. Select Open teleprompter to display the always-on-top prompt.
  3. For a live slideshow, enable Sync & control PowerPoint before starting it.

Troubleshooting

If sync reports that PowerPoint is busy, close any PowerPoint dialog such as Repair or Enable Editing, then wait for the status to resume. If a protected or damaged presentation cannot be read directly, use Load from PowerPoint after opening it in PowerPoint.

The overlay never takes keyboard focus, so clicker arrow and Page Up/Down presses continue to reach the slideshow. To close a click-through overlay, use Ctrl + Alt + Shift + Esc.

The teleprompter is hidden when you share or record your screen on Windows 10 version 2004 or later and Windows 11. On earlier versions of Windows 10, a black box may appear in its place.
